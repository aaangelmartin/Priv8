El agente hace el trámite. Los datos se quedan contigo.

Priv8 es una capa de privacidad para agentes de IA que usan pantallas. Cada dato sensible llega al modelo como un token, por ejemplo ‹IBAN_1-propio›, y el valor real solo se escribe en local.

Ejecutarlo en tu máquina

  1. Descomprime el ZIP (o clona el repositorio) e instala uv; para la web, Node 20 y pnpm.
  2. Sin claves: uv sync y make demo. Peticiones al modelo con un valor real: 0.
  3. En vivo: cp .env.example .env con ANTHROPIC_API_KEY, y doble clic en Demo Priv8.command (en Linux, make panel).
  4. Pruebas: make test. Todo, en el README.
