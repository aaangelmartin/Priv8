El agente hace el trámite. Los datos se quedan contigo.

Priv8 es una capa de privacidad para agentes de IA que usan pantallas. Cada dato sensible llega al modelo como un token, por ejemplo ‹IBAN_1-propio›, y el valor real solo se escribe en local. Este documento reúne todo lo entregado.

Ejecutarlo en tu máquina

  1. Descomprime Priv8-main.zip (o clona el repositorio) e instala uv. Para la parte web, Node 20 y pnpm; para Android, Android Studio con un emulador de Android 14.
  2. Sin claves: uv sync y make demo. Reproduce las dos escenas con el núcleo real y respuestas del modelo grabadas; al final cuenta las peticiones al modelo con un valor real: 0.
  3. En vivo: cp .env.example .env y pon ANTHROPIC_API_KEY. En macOS, doble clic en Demo Priv8.command: abre un panel con un botón para B2B y otro para B2C. En Linux, make panel.
  4. Pruebas: make test.

Todo está detallado en el README del repositorio: descripción, requisitos, instalación, configuración, ejecución y pruebas. Los datos, bancos y empresas de la demo son inventados.
